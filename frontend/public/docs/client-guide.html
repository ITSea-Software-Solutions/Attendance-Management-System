What the system does

  • Verified worker identity. Every worker is registered against their Aadhaar — upload the e-Aadhaar PDF and the form fills itself (name, DOB, gender, address, photo), or type the 12-digit number. Duplicate registrations are blocked automatically, even across different vendors.
  • Fingerprint attendance. Workers clock IN and OUT at site gates with a fingerprint scan — no cards to lose, no buddy-punching.
  • Multi-company, multi-vendor. Vendors register and manage their workforce; companies approve which vendors may deploy to their sites. Each side sees exactly their own data.
  • Deployments with date ranges. A worker is deployed to a company for a defined period; attendance is only accepted while the deployment is active.
  • Live reporting. Daily attendance summaries, per-worker analytics with monthly breakdowns, and an “exceptions” view showing everyone currently inside.
  • Document vault. Aadhaar PDFs and other ID documents are stored encrypted and privately — downloadable only by authorized roles, with every access logged.
  • Full audit trail. Every sensitive action (registrations, approvals, attendance, document downloads) is recorded with who, what, and when.

The flow, end to end

  1. Super adminCreate the company and the vendorBoth get admin login credentials at creation.
  2. Vendor adminRequest access to the companyCompany Access page → send request.
  3. Company adminApprove the vendorVendor Approvals page → Approve (or reject with a reason).
  4. VendorRegister workersAadhaar PDF auto-fill or manual 12-digit entry, then fingerprint enrollment. Aadhaar is mandatory; duplicates are refused.
  5. Vendor adminDeploy workers to the companyDeploy Workers → pick workers, company, and a date range.
  6. Company adminCreate gate usersOne login per entry point (main gate, departments, checkpoints).
  7. Gate userMark attendanceMark Attendance → worker places finger → IN or OUT is recorded with score, time, and gate.
  8. EveryoneWatch the numbersDaily summaries, worker analytics, exceptions — each role sees its own slice.

How-to, role by role

Super Admin

Demo login: superadmin@ams.local

  • Create a company: Companies → Add Company → fill details → save. Then “Create Admin” to issue the company admin login.
  • Create a vendor: Vendors → Add Vendor → fill details and set the vendor admin’s email + password.
  • Manage users: Users → create or edit any account, any role.
  • Super admin also sees every list (workers, attendance, approvals) across all companies and vendors.

Company Admin

Demo login: company@ams.local

  • Approve a vendor: Vendor Approvals → Pending tab → Approve. Reject requires a reason; you can also Suspend later.
  • Create gate users: Users → Add User → role Gate User → assign the gate / department name. Create one per entry point.
  • See who’s on site: Attendance → Exceptions shows every worker currently IN without an OUT.
  • Reports: Attendance shows one row per worker per day (first IN, last OUT, hours). Click any row for that worker’s full analytics.

Vendor Admin & Operator

Demo login: vendor@ams.local

  • Get access to a company: Company Access → Request. Wait for the company to approve (status shows on the same page).
  • Register a worker: Workers → Register Worker.
    1. Aadhaar — upload the e-Aadhaar PDF (password: first 4 letters of the name in CAPITALS + birth year, e.g. RAME1985) and the form auto-fills. No PDF? Choose “Enter Manually” and type the 12-digit number. Aadhaar is mandatory for every worker.
    2. Details — review the auto-filled data, add phone etc.
    3. Fingerprint — worker places a finger on the scanner (2 scans). The worker becomes Active.
    4. Photo — capture a live photo, then confirm.
  • Deploy: Deploy Workers → select workers → company → start / end dates. Cancel is possible until the worker is currently inside a site.
  • Track: Workers and Attendance pages have Current / Previous / All tabs; click a row for per-worker analytics and monthly totals.

Gate User

Demo login: gate@ams.local

  • Mark attendance: Mark Attendance → worker places finger → the system identifies them and shows name + photo → confirm IN or OUT.
  • The same screen warns if the worker isn’t deployed to your company today.
  • Exceptions: see everyone currently inside your site at any moment.
Attendance rules worth knowing: a worker must be Active (fingerprint enrolled) and on an active deployment for today at your company; IN and OUT must alternate; every record stores the score, gate, and operator for the audit trail.

FAQ & troubleshooting

“Too many attempts” at login

Five wrong passwords in a minute locks the login for that minute (brute-force protection). Wait 60 seconds and try again.

“A worker with this Aadhaar number is already registered”

Someone — possibly another vendor — has already registered this person. Each Aadhaar can exist once in the system. If you believe this is an error, contact your administrator.

Worker stuck on “Pending”

Pending means no fingerprint yet. Open the worker → Edit → Fingerprint step → enroll. The worker turns Active automatically.

Fingerprint scanner not detected

On gate PCs the SecuGen scanner must be plugged in and its local service running (your IT team installs this once). The demo server needs no scanner — it simulates captures.

Can’t cancel a deployment

Deployments lock after first attendance, and can only be cancelled while the worker is clocked OUT — never while they’re inside a site.

Forgot password

Password reset is done by your administrator (company admin or super admin) — self-service reset is coming in a later release.
