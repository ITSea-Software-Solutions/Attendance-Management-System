TrueCrew for Android

Sign up, register workers END-TO-END and mark attendance by FINGERPRINT or FACE. On-device ML face checks (real face, eyes open) gate every photo; the in-app Face tab identifies workers by camera. USB-OTG SecuGen captures activate when the licensed SecuGen Android SDK (FDxSDKPro.aar) is bundled — until then fingerprint simulates, face is fully real. Works offline and syncs automatically.

TrueCrew Gate Station for Windows

Desktop station — full worker registration with REAL SecuGen fingerprint capture (via the SGIBIOSRV service) + gate attendance, offline queueing. Built on GitHub's Windows runners.

⬇ Download v0.9.14 preview (ZIP, 14 MB)

Windows 10/11 64-bit. Unzip anywhere and run truecrew.exe. For real fingerprint capture just install the SecuGen FDx SDK (driver) and plug in the scanner — the app talks to it directly. WebAPI/simulation are automatic fallbacks.

Biometrics the apps support

👍

Fingerprint — from day one

Any supported USB scanner — SecuGen Hamster Pro 20 is our current test device, with Mantra, Morpho and Startek pluggable via the same driver layer. On Windows and Android (USB-OTG); identification runs on the device, so gates keep working with no internet.

Note: a phone's built-in fingerprint sensor can only unlock the phone — no app can use it to identify workers. That's an OS rule on every Android device, which is why gates use the USB scanner.

📷

Face — live on the web portal

Uses the device camera only — no extra hardware, works on any phone or PC browser. Workers are enrolled automatically from their registration photo; the gate's Face tab identifies them and the server re-verifies every mark. For supervised gates (guard present) today; liveness checks and in-app face arrive next.

🪪

Backup options

QR ID-badges (guard sees the worker's photo on scan) and NFC tap cards are available as fallbacks. Gate operators unlock the app itself with their device's own fingerprint/face (Android biometrics, Windows Hello).
